# Coding Agent

The Forge's software engineering agent. Its lead, the Engineering Director,
picks a proportionate team for each request from the seven divisions below,
then runs the divisions in order, phase by phase: analyze, plan, design,
build, review.

Attachments lend a specialist to another division for the build phase. The
Debugging Specialist (Quality) works inside Development on bug-fix requests,
so the Tech Lead can assign it work alongside the developers instead of both
divisions fixing the same bug separately.
